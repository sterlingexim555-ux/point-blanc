POINT BLANC MOBILE — iPHONE WEB APP

This is a PWA prototype with a Point Blanc checklist, custom cooldown, manual loss-limit tracking, trade journal, streak trigger and CSV export.

LIMITATIONS: It cannot block TradingView, MT5 or Exness apps. Results/P&L are manual. No broker integration, password unlock, cloud sync or Screen Time integration. Data stays in this browser's local storage and can be lost if website data is cleared. It is not a reliable enforcement boundary.

INSTALL:
1. Upload all files in this folder to an HTTPS static host (GitHub Pages or another static host).
2. Open the hosted HTTPS address in Safari on iPhone.
3. Tap Share -> Add to Home Screen -> Add.
4. Open Point Blanc from the Home Screen and test it.
